# Google Colab

## What is Google Colab

**Google Colab** is a cloud-based platform by Google that allows users to run **Python notebooks in the browser**, similar to **Jupyter Notebook**.

Instead of running code on a local computer, the code runs on **Google's cloud servers**, and the results are returned instantly to the browser.

---

## How It Works

A Colab notebook contains **cells** that can include code or text.

When a code cell is executed:

- The code runs on a **remote machine in Google's cloud**
- The results are **displayed immediately in the notebook**

This allows users to work with powerful computing resources without owning expensive hardware.

---

## Key Advantages

- **Free access to GPUs** for machine learning and AI tasks.
- **Easy collaboration**, similar to Google Docs.
- **Integration with Google Drive** for storing notebooks and datasets.
- **No local setup required** – everything runs in the browser.

---

## Why GPUs Matter for AI

AI and deep learning models perform heavy mathematical operations such as **matrix multiplications**.

GPUs are designed for **parallel computations**, making them much faster than CPUs for training and running AI models.

---

## Downsides

- Sessions can **disconnect or reset**, especially in the free version.
- Packages often need to be **reinstalled in each new session**.
- Running code in the cloud can introduce **some latency**.
